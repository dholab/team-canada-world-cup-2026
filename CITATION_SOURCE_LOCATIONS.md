# Citation source locations

Note that supporting evidence for assertions is recorded in this file. I've found this sort of explicit cross-validation useful when performing LLM-assisted background research. — DHO

## How to read this file

Each numbered reference below lists the manuscript claim(s) it supports, the exact location consulted in the source, and a verbatim quotation of the supporting passage. For each claim we record whether the source **supports** it fully (“yes”), only in part (“partial”, e.g. the sentence merges two references and this source covers only one clause, or the source is close but weaker/broader than the claim), or could not be verified from the material we could access (“unverifiable”). Verification level records whether we consulted the full text (via PubMed Central), the abstract only, or, for data sources and websites, that no PubMed record exists.

Bibliographic data are from PubMed. This documentation was produced with LLM assistance and then cross-checked; where a source only partly supports a claim, that is stated explicitly rather than smoothed over.
